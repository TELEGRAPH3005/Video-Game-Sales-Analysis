# Video Game Sales Analysis

## Project Overview
This project explores video game sales data using Python to identify trends and patterns across the video game industry.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Kaggle

## Project Objectives
- Explore and understand video game sales data.
- Analyze sales across different platforms and genres.
- Examine regional sales patterns.
- Use data visualizations to communicate findings.

## Data Analysis
The analysis uses Python and Pandas for data exploration and manipulation, with Matplotlib for visualizing trends and comparisons.

## Skills Demonstrated
- Data cleaning and preparation
- Exploratory Data Analysis (EDA)
- Data aggregation
- Data visualization
- Python programming

## Project File
- `Video_Game_Sales_Analysis.ipynb` — Jupyter Notebook containing the analysis.

## Conclusion
This project demonstrates the use of Python for exploratory data analysis and the ability to extract insights from a dataset.
